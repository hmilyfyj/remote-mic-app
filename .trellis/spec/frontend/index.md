# SwiftUI 界面规范

此处 frontend 指 Mac 原生 SwiftUI 界面。Web、iOS、Windows 各自仓库边界见 [AGENTS.md](../../../AGENTS.md)。

## Pre-Development Checklist
- 读 [目录](directory-structure.md)、[组件](component-guidelines.md)、[状态](state-management.md) 和 [类型](type-safety.md)。
- 涉及异步行为时读 [生命周期](hook-guidelines.md)。
- UI 改动先读 [design-qa.md](../../../design-qa.md)；Onboarding 改动先读 [产品规范](../../../feature/first-run-onboarding/PRODUCT_SPEC.md) 与 macOS 附件。

## Quality Check
执行 [界面验证](quality-guidelines.md)，逐项说明自动化、截图与真实交互结果。
