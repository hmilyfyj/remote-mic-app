# 界面目录

`Sources/RemoteMic/SettingsView.swift` 为设置入口；`MacShortcutEditor.swift` 为页面内快捷指令选择组件；`OnboardingView.swift` 为引导界面；`Localization.swift` 管理本地化入口。
`SettingsScreenshotRenderer.swift` 与 `OnboardingScreenshotRenderer.swift` 提供项目截图工具。

优先按既有组件职责扩展。新增命名遵守 [FILE_NAMING.md](../../../FILE_NAMING.md)，界面验证手册放在 `Testing/`。
