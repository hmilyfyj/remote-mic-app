# 遥控按键控制语音模式

## 使用

候选分支 `feat/448-microphone-only`。在“按键映射”选择一个普通按钮，选择单击、双击或长按，然后在“语音模式”分组绑定：

- 切换语音模式：在仅麦克风和 Fn 语音输入之间切换。
- 使用仅麦克风：固定选择仅收音。
- 使用 Fn 语音输入：固定选择 Fn 模式。

推荐将自己空闲的菜单键单击绑定为“切换语音模式”；也可用两个不同按钮分别绑定固定模式。动作只选择模式，语音按钮继续负责按住收音。既有 Fn 长按/点按及来源切麦设置按当前配置生效。
忙时显示当前模式与待选择，结束后应用；连续切换参考最后一次待选择，因此等待期间按两次 toggle 可以取消第一次。Command 模式下 toggle 先进入仅麦克风。
绑定随现有设备/按钮配置保存；语音模式为应用当前设置。新动作使用内部执行入口、没有键盘快捷键，并关闭按住连发。程序保持原有默认按钮映射，由用户选择具体绑定。

## 逐项验收

准备：本机更新到此次候选，确认遥控器连接及输入监控/辅助功能权限，打开按键映射并启用自定义按钮；记录系统、硬件和输入法版本。

| 用例 | 操作 | 预期与失败判定 |
| --- | --- | --- |
| B01 单键切换 | 菜单单击绑定 toggle，闲置状态点击两次 | Fn 与仅麦克风来回切换；一次点击切换一次，配置之外的按键保持原行为 |
| B02 固定模式 | 两个按钮分别绑定仅麦克风/Fn，反复按同一个 | 始终选择指定模式；动作本身不开始语音或发送快捷键 |
| B03 恢复期操作 | 松开语音键，在恢复等待期间按切换按钮 | 页面显示待选择，会话完成后应用；当前音频和尾字完整 |
| B04 快速再切 | 等待期间快速按两次 toggle | 待选择回到当前模式并取消，结束后保持当前模式 |
| B05 三种手势 | 单击/双击/长按分别绑定三个动作 | 每种手势只执行对应动作，长按持续保持时不反复切换；普通语音键手势保持既定行为 |
| B06 保存 | 重启、导出再导入；切换设备配置 | 对应按钮绑定保持，旧配置仍可导入，设备间绑定按既有档案隔离 |
| B07 语音结果 | 指定 Fn 后按语音键；指定仅麦克风后在录音软件收音 | Fn 产生正确触发和释放；仅麦克风保持零语音快捷键并输出完整声音 |
| B08 页面 | 800×650、中文/英文、浅色/深色 | 三项动作可读可选，提示与触发方式清晰，无裁切 |

失败包括一次手势反复切换、待请求丢失、错误目标、旧回调覆盖、当前语音截断或发送了额外快捷键。音频完整性继续按 `HardwareVoiceAudioContract.md` 及 `MicrophoneOnly.md` 验收。
