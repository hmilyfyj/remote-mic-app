# Mac 快捷指令

## 使用与验收

1. 在系统“快捷指令”App 中创建一条测试指令，例如只显示一条通知；先在系统 App 内运行并完成所需授权。
2. 在 SayAll Local 的“按键映射”选择普通按键和单击、双击或长按，选择“运行 Mac 快捷指令”。语音键继续使用原语音流程。
3. 搜索并选择指令，确认列表选择本身只保存设置。点击播放图标进行一次明确测试，再用遥控器触发，观察“正在运行”和“运行完成”。
4. 用含“等待 5 秒”的测试指令连续按键，确认执行期间同一指令只启动一次。执行完成后可再次启动。
5. 重启应用并检查绑定；为第二个遥控器设置另一条指令，确认设备配置独立。导出并重新导入设置，确认三个触发方式的绑定均保留。
6. 在系统 App 中重命名指令，刷新后确认名称更新且绑定保留；删除测试指令后刷新，确认显示不可用并允许重新选择。
7. 验证空列表、无搜索结果、读取失败和运行失败；从行内“打开快捷指令”入口检查操作和权限。
8. 回归 Fn 语音输入、麦克风恢复模式及延迟，确认与原版本行为一致。

## 实现与边界

- 通过公开的 `/usr/bin/shortcuts list --show-identifiers` 获取列表，通过 `shortcuts run <UUID>` 执行；名称保存在配置中用于展示，命令参数只使用 UUID。
- 列表读取最多 15 秒、1 MiB；运行最多等待 120 秒。工作进程退出码为零时显示完成，具体业务结果以快捷指令自身为准。
- 超时会结束本应用启动的命令行进程。系统快捷指令或其启动的外部操作可能继续，已经产生的修改仍然生效；重试前先在快捷指令 App 中核实。
- 同一个 UUID 在本应用等待执行期间去重；不同快捷指令可以同时运行。交互和权限弹窗由 macOS 与快捷指令负责，切换到系统 App 完成。
- 日志不记录快捷指令名称、UUID、输出或系统错误原文。导出的用户配置包含所选指令名称和 UUID，分享配置前自行检查。
- 旧配置缺少新增字段时按未绑定处理。另一台 Mac 上缺少相同指令时需重新选择。

## 自动验证

```sh
REMOTE_MIC_LOCAL_ONLY=1 swift test --filter MacShortcuts
REMOTE_MIC_LOCAL_ONLY=1 REMOTE_MIC_TEST_SHORTCUTS_LIST=1 swift test --filter MacShortcuts
REMOTE_MIC_LOCAL_ONLY=1 swift test
SKIP_SWIFT_PACKAGE_BUILD=1 REMOTE_MIC_LOCAL_ONLY=1 zsh scripts/test.sh
REMOTE_MIC_LOCAL_ONLY=1 zsh scripts/build-app.sh
zsh scripts/verify-app.sh
```

自动化覆盖括号及多行名称、标识参数、配置持久化与导入导出、多设备隔离、旧配置、长录音备份、宿主派发、重复触发、失败状态、输出丢弃、进程超时和输出上限。测试进程仅使用固定的 printf、sleep 和 yes 测试数据，用户现有快捷指令留待人工验收。

截图通过生产 `SettingsView` 和隔离配置渲染；`REMOTE_MIC_SETTINGS_SCREENSHOT_MAC_SHORTCUT=ready|missing|error` 提供无副作用的固定数据。检查中英文、浅色和深色的 1020×772 及 800×650 压力布局。800×650 属于截图工具的压力尺寸，实际窗口最小尺寸仍为 1020×772。
